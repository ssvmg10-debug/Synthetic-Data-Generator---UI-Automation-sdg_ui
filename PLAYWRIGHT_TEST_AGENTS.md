# Playwright Test Agents Integration

## 🎭 Overview

This project integrates **Playwright Test Agents** - AI-powered agents for intelligent test generation, execution, and self-healing.

**Official Documentation**: https://playwright.dev/docs/test-agents

## Architecture

### Three Playwright Test Agents

1. **🎭 Planner Agent**
   - Explores your app and produces a Markdown test plan
   - Input: Clear test request, seed test, optional PRD
   - Output: Human-readable test plan saved as `specs/*.md`

2. **🎭 Generator Agent**
   - Transforms Markdown plans into executable Playwright tests
   - Verifies selectors and assertions live during generation
   - Output: TypeScript test files in `test_outputs/*.spec.ts`

3. **🎭 Healer Agent**
   - Automatically repairs failing tests
   - Replays failing steps and inspects current UI
   - Suggests patches (locator updates, wait adjustments, data fixes)
   - Re-runs tests until they pass or hit guardrails

## Setup

### 1. Install Dependencies

```bash
cd backend
npm install
```

### 2. Install Playwright Browsers

```bash
npx playwright install
```

### 3. Initialize Playwright Test Agents

```bash
npx playwright init-agents --loop=vscode
```

Or via API:
```bash
POST http://localhost:8000/ui/playwright-agents/init
```

## API Endpoints

### Initialize Agents

```http
POST /ui/playwright-agents/init
```

Initializes Playwright Test Agents definitions.

### Planner Agent

```http
POST /ui/playwright-agents/planner
Content-Type: application/json

{
  "request": "Generate a plan for guest checkout",
  "base_url": "https://sauce-demo.myshopify.com/",
  "prd": "Optional product requirements"
}
```

**Response:**
```json
{
  "success": true,
  "plan_file": "specs/generate-a-plan-for-guest-checkout.md",
  "plan_content": "# Test Plan: ...",
  "message": "Test plan generated successfully"
}
```

### Generator Agent

```http
POST /ui/playwright-agents/generator
Content-Type: application/json

{
  "plan_file": "specs/generate-a-plan-for-guest-checkout.md"
}
```

**Response:**
```json
{
  "success": true,
  "test_file": "test_outputs/generate-a-plan-for-guest-checkout.spec.ts",
  "test_content": "import { test, expect } from '@playwright/test';...",
  "message": "Playwright test generated successfully"
}
```

### Healer Agent

```http
POST /ui/playwright-agents/healer
Content-Type: application/json

{
  "test_file": "test_outputs/checkout-test.spec.ts",
  "error_message": "Timeout waiting for selector \"#submit-button\"",
  "max_retries": 3
}
```

**Response:**
```json
{
  "success": true,
  "healed": true,
  "actions": [
    "Identified failed selector: #submit-button",
    "Replaced ID selector with data-testid: [data-testid='submit-button']"
  ],
  "message": "Test healed successfully"
}
```

## Existing Workflow Integration

### Standard Workflow (Our Agents)

When you use the standard UI automation endpoint:

```http
POST /ui/run
Content-Type: application/json

{
  "raw_input": "1. Open https://example.com\n2. Click login\n3. Fill form",
  "use_synthetic_data": false

```

Our agents automatically use Playwright Test Agents internally for enhanced capabilities.

### Direct Playwright Agent Workflow

For more control, use the dedicated endpoints:

1. **Create Test Plan** → `/ui/playwright-agents/planner`
2. **Generate Test** → `/ui/playwright-agents/generator`
3. **Execute Test** → Run via Playwright directly
4. **Heal if Failed** → `/ui/playwright-agents/healer`

## Configuration

### Agent Integration Flags

Each agent can be configured to use or bypass Playwright Test Agents:

```python
# In Python code
planner = PlannerAgent(use_playwright_agents=True)
generator = GeneratorAgent(use_playwright_agents=True)
healer = HealerAgent(use_playwright_agents=True)
```

## Seed Tests

Seed tests provide environment setup for the Planner agent:

```typescript
// test_outputs/seed.spec.ts
import { test, expect } from '@playwright/test';

test('seed', async ({ page }) => {
  // Navigate and set up environment
  await page.goto('https://your-app.com');
  
  // Login or other initialization
  await page.fill('#username', 'test@example.com');
  await page.fill('#password', 'password123');
  await page.click('button[type="submit"]');
  
  await page.waitForLoadState('networkidle');
});
```

The Planner uses this seed test to understand your app's context.

## Troubleshooting

### Agents Not Initializing

```bash
# Reinstall Playwright
npm install @playwright/test --save-dev
npx playwright install
```

### Tests Failing

1. Check logs in `test_outputs/logs_*.txt`
2. Review screenshots in `test_outputs/screenshot_*.png`
3. Use Healer agent to auto-fix
4. Run in debug mode: `npx playwright test --debug`

### Selectors Breaking

The Healer agent should automatically fix most selector issues. If not:
- Use data-testid attributes in your app
- Check the locator registry: `GET /ui/locators`
- Update selectors manually if needed

### Example 2: Login Flow with Healing

```python
# 1. Generate plan and test
plan_result = planner_agent(request="Test login flow")
test_result = generator_agent(plan_file=plan_result['plan_file'])

# 2. Execute (may fail)
execution = executor.execute(test_result['test_file'])

# 3. Auto-heal if failed
if execution['status'] == 'failed':
    heal_result = healer_agent(
        test_file=test_result['test_file'],
        error_message=execution['error']
    )
```
